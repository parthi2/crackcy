# Crackcy 🎆
A modern PHP & JavaScript e-commerce web application designed for retail and wholesale fireworks (cracker) stores, featuring live client-side search, multi-theme UI switcher, dynamic cart calculator, and automated order processing.

---

## 🌟 Key Features

* **🎨 6 Dynamic Color Themes:** Instantly switch between custom themes (Gold & Crimson, Dark Cyber, Royal Purple, Factory Emerald, Sunset Fire, and Minimalist Glass) with live session persistence.
* **⚡ Real-time Product Search & Sorting:** Instant client-side filtering by product name, category, or SKU, alongside flexible multi-tier sorting options.
* **🛒 Interactive Cart & Stepper System:** Seamless increment/decrement quantity steppers with real-time subtotal calculation, animated summary metric cards, and local storage retention.
* **🎆 Festive Visual Effects:** Integrated particle firework animation canvas running smoothly in the background.
* **📦 Complete Order Management:** Secure MySQL database backend handling order placement, automatic sequence number generation (`YYYY-sequence`), item subtotals, and administrative oversight.
* **📱 Responsive Design:** Built using Bootstrap 5 and custom CSS layouts optimized for both mobile-first purchasing and desktop browsing.

---

## 🛠️ Technology Stack

* **Backend:** PHP, MySQL (PDO Transactions)
* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, FontAwesome
* **Libraries:** SweetAlert2 (for interactive product image lightboxes)
